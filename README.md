# TZD Hero Quest

เกมจำลองภารกิจของคณะทำงาน Thailand Zero Dropout (TZD) ระดับตำบล
ผู้เล่นสวมบทนักสืบ เดินสำรวจ "ตำบลธารทอง" แบบ 3D และร่วมกับผู้กล้าอีก 5 บทบาท
พาเด็กที่หลุดจากระบบการศึกษากลับสู่เส้นทางการเรียนผ่าน 6 ด่าน

## เล่นเกม

เปิดผ่าน GitHub Pages: `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแรก (ภาพปก ปุ่มเริ่มเล่น และคำอธิบายเกม) |
| `game3d.html` | ตัวเกม 3D ตำบลธารทอง |
| `.nojekyll` | ให้ GitHub Pages เผยแพร่ไฟล์ตามที่เป็น ไม่ผ่าน Jekyll |

## วิธีเผยแพร่บน GitHub Pages

1. อัปโหลดไฟล์ทั้งหมดไว้ระดับนอกสุดของ repository (ไม่อยู่ในโฟลเดอร์ย่อย)
2. ตั้ง repository เป็น **Public**
3. ไปที่ **Settings → Pages** เลือก Source = **Deploy from a branch**, Branch = **main**, Folder = **/ (root)** แล้วกด Save
4. รอ 1–2 นาที ลิงก์จะแสดงที่ด้านบนของหน้า Pages

## การควบคุม

- มือถือ: จอยสติ๊กซ้ายล่างเพื่อเดิน ลากนิ้วบนจอเพื่อหมุนกล้อง แตะปุ่มคุยเมื่ออยู่ใกล้ตัวละคร
- คอมพิวเตอร์: WASD หรือลูกศรเพื่อเดิน Shift วิ่ง ลากเมาส์หมุนกล้อง กด E เพื่อคุย

## หมายเหตุ

- เกมเป็นไฟล์ HTML ล้วน ไม่ต้องติดตั้งหรือ build ใด ๆ
- ต้องเชื่อมต่ออินเทอร์เน็ต เพื่อโหลด three.js (cdnjs) และฟอนต์ (Google Fonts)
- ชื่อตำบลและเรื่องราวของเด็กในเกมเป็นเรื่องสมมุติ ใช้เพื่อการเรียนรู้ของคณะทำงานเท่านั้น
